# Реализованный функционал CatalogService

## 1. Получение данных каталога

Реализованы следующие эндпоинты для получения информации из каталога:

- **`GET /catalog/categories`** — получение списка доступных категорий.
- **`GET /catalog/objects`** — получение списка объектов каталога. Поддерживаются следующие параметры:
  - `page` — номер страницы для постраничной выдачи;
  - `category_id` — фильтрация объектов по идентификатору категории;
  - `q` — поисковый запрос для поиска объектов.
- **`GET /catalog/objects/{id}`** — получение информации о конкретном объекте каталога по его идентификатору.

## 2. Импорт данных из внешних API

Реализованы четыре эндпоинта для первоначального наполнения каталога объектами с использованием внешних API:

- **`POST /catalog/objects/films/import`** — импорт фильмов с использованием Unofficial Kinopoisk API.
- **`POST /catalog/objects/anime/import`** — импорт аниме с использованием Shikimori API.
- **`POST /catalog/objects/games/import`** — импорт компьютерных игр с использованием Steam API.
- **`POST /catalog/objects/books/import`** — импорт книг с использованием ReBooks API.

Импортируемые данные используются для первоначального заполнения соответствующих категорий каталога.

## 3. Запуск

Клонируйте репозиторий, перейдите в папку Shelf, из неё выполните команду Copy-Item **`Copy-Item .env.example .env`** и после запустите проект через **`docker compose up --build`**
